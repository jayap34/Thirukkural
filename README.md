# Thirukkural · திருக்குறள் · ثيروكورال
### Wisdom Meets Vision — Thirukkural in Arabic

A trilingual digital edition of the **Thirukkural**, the classic Tamil treatise of **1,330 couplets (kurals)** by the poet-philosopher **Thiruvalluvar**, presented in **Tamil, English and Modern Standard Arabic**.

Dedicated to the Father of the Nation, **H.H. Sheikh Zayed bin Sultan Al Nahyan**.
Compiled & curated by **Dr. Jayaprakash Ponraj** · Abu Dhabi, UAE.

---

## 📖 What's inside

| | |
|---|---|
| **Books** | 3 — Virtue (அறத்துப்பால்), Wealth (பொருட்பால்), Love (காமத்துப்பால்) |
| **Chapters** | 133 (with Tamil, English & Arabic names) |
| **Kurals** | 1,330 |
| **Languages** | Tamil (couplet + transliteration + commentary), English, Arabic |

Every kural shows the Tamil couplet, romanised transliteration, English verse, Tamil commentary, and a **faithful, fully-vocalised Modern Standard Arabic** translation — **1,330 distinct verses**, one per kural.

## ✨ Features

- **Full-text search** across Tamil, English, transliteration, Arabic, and chapter names
- **Filter** by book (Virtue / Wealth / Love) and by any of the 133 chapters
- **Card + full-screen modal** view with keyboard navigation (← → Esc)
- **Trilingual Foreword & Dedication** and a **Heritage Gallery** of Tamil Nadu & UAE
- **Print** a single kural, the current page, or the **entire 1,330-kural book** (with title, dedication & foreword pages)
- Random kural, reading-progress bar, responsive design

## 🚀 Publish on GitHub Pages

1. Upload the contents of this folder to a repository (`index.html`, `kurals_data.js`, `Photos/`, `.nojekyll`).
2. Repo **Settings → Pages → Build and deployment → Deploy from a branch**, select `main` / root.
3. Live at `https://<username>.github.io/<repo>/`.

No build step — a single static page that reads `kurals_data.js` and renders client-side. Works offline too.

## 📝 Note on the Arabic

The Arabic verses are faithful Modern Standard Arabic renderings of each kural's meaning, fully vocalised. They are scholarly drafts and benefit from a final review by a native Arabic + Tamil scholar before formal print publication.
